### Smart Student Hub
 Smart Student Hub is a simple frontend website built using HTML and CSS.
 It is designed to showcase different courses and help users explore available learning options in a clean and organized layout.
#### Technologies Used
- HTML5
- Tailwind CSS
#### Key Features
- Clean and simple UI design
- Course listing layout
- Responsive basic structures
